Screenshots for the Work page cards live in this folder.

  a2h.jpg             A2H Badminton & Indoor Sports
  gospel-supplies.jpg Gospel Supplies by Shekinah
  zyan-events.jpg     Zyan Events
  naveen-joshua.jpg   Naveen Joshua

To add a screenshot for another project, put the file here and set its
"image" line in src/site.ts. A card with no matching file shows no image.
